## Étape 1: Installation de Blender
1. Installer à partir de ce site: https://www.blender.org/download/
2. Une fois le téléchargement complété, extraire le fichier.
3. À partir du terminal, se rendre dans le fichier.
4. Exécuter **./blender** pour lancer l'application.
